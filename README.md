# Interactive Web Projects

A collection of browser-based interactive applications built with Processing.js, covering games, simulations, computer graphics, and algorithmic visualizations.

## Overview

This repository contains over 70 interactive web applications demonstrating various concepts in computer science, mathematics, and physics. All projects run directly in the browser and are built using Processing.js for graphics rendering and mathematical computations. These are ported from Khanacademy where I originally wrote most of the code.

## Categories

### Games
Complete game implementations featuring physics simulation, collision detection, and game mechanics:
- **Data Defense**: Tower defense shooter game with 30+ weapon types and persistent save system
- **Clash Royale**: Strategy game clone with unit AI and pathfinding
- **Space Golf**: Gravity-based puzzle game with orbital mechanics
- **Fruit Ninja**: Particle systems and mouse interaction detection
- **Cave Explorer**: Procedural obstacle generation with collision physics

### Computer Graphics & Visualization
Graphics programming demonstrating fundamental rendering techniques:

#### 3D Graphics & Projection
- **3D Mandelbrot Set**: Complex number iteration with 3D visualization
- **3D DNA Helix**: Matrix transformations and 3D rotation
- **3D Sphere**: Perspective projection and depth-based shading
- **Vector Fields**: Mathematical field visualization with particle systems

#### Fractals & Mathematical Art
- **Interactive Julia Set**: Real-time fractal generation with complex parameter manipulation
- **Tree Fractals**: Recursive branching algorithms (Sierpinski variations)
- **Barnsley Fern**: L-system implementation and iterative function systems
- **Thue-Morse Koch**: Self-similar sequence to fractal conversion

#### Ray Tracing & Advanced Rendering
- **Monte Carlo Ray Tracer**: Raytracing engine written from scratch featuring sphere intersection algorithms and global illumination, along with both diffuse and specular lighting
- **Metaballs**: Marching squares algorithm for implicit surface rendering
- **Lava Lamp**: Blob physics with surface tension simulation

### Physics Simulations
Real-world physics modeling with numerical integration:

#### Particle Systems & Dynamics
- **Cloth Simulation**: Verlet integration for deformable objects
- **Wave Simulation**: Discrete wave equation solving (6400+ nodes)
- **Molecule Dynamics**: N-body collision detection and response
- **Marble Machine**: Physics-based marble runs with constraint solving

#### Specialized Simulations  
- **Natural Selection**: Evolutionary algorithms and genetic programming with organism AI
- **Rocket Simulator**: Rocket science and gravitational physics
- **Heat Transfer**: Thermal diffusion visualization
- **Black Hole**: Gravitational field simulation with particle advection

### Algorithms & Data Structures
Educational visualizations of fundamental computer science concepts:
- **BFS Visualization**: Breadth-first search pathfinding
- **Dijkstra's Algorithm**: Shortest path optimization
- **Maze Generation**: Recursive backtracking algorithms
- **DLA (Diffusion-Limited Aggregation)**: Stochastic growth simulation
